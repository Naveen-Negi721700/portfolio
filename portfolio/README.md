# Naveen Negi — Portfolio

```
npm install
npm run dev
```

- Edit all your content in `src/data.js`
- Replace `public/me.jpg` with your photo (a placeholder shows until you add one)
- Your resume is at `public/Naveen_negi_resume.pdf`
- Build for deployment: `npm run build` (deploy the `dist` folder, e.g. on Vercel)
