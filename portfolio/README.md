# Naveen Negi --- Personal Portfolio

A modern, responsive personal portfolio built to showcase my projects,
technical skills, and journey as a developer. The website provides a
simple way to explore my work, learn about my background, and get in
touch.

## ✨ Features

-   **Responsive Design:** Works across desktop, tablet, and mobile
    devices.
-   **Projects Showcase:** Highlights selected projects with
    descriptions, technologies, and links.
-   **About Section:** Introduces my background and interests as a
    developer.
-   **Skills Section:** Displays my programming languages, tools, and
    technologies.
-   **Contact Section:** Makes it easy for visitors and recruiters to
    connect.
-   **Clean UI:** A simple, modern interface with smooth navigation.

## 🛠️ Tech Stack

-   **React.js** --- Component-based user interface.
-   **Tailwind CSS** --- Utility-first styling and responsive layouts.
-   **JavaScript (ES6+)** --- Application logic and interactivity.
-   **Vite** --- Development server and build tooling (if your project
    uses Vite).

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

``` bash
git clone https://github.com/Naveen-Negi721700/portfolio.git
```

### 2. Open the project folder

``` bash
cd your-portfolio-repository
```

### 3. Install dependencies

``` bash
npm install
```

### 4. Start the development server

``` bash
npm run dev
```

Open the local URL shown in your terminal (usually
`http://localhost:5173`).
